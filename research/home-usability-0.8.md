# Keynest 0.8：以查找与复制为主的首页

2026-09-29。目标是让用户把已保存的 API 密钥当作本地收藏来取用：打开、找到平台、明确复制一把密钥。第一次使用也能从熟悉的平台图标开始。

| 调整前 | 调整后 | 原因 |
| --- | --- | --- |
| 解锁后进入三栏管理，先理解条目和工具关系 | 默认进入首页，已保存平台以卡片展示 | 日常取用不依赖学习管理结构 |
| 复制入口主要位于列表与详情 | 每把密钥都有直接复制按钮和短暂「已复制」反馈 | 保持动作就近、反馈明确，密钥明文不出现在首页 |
| 同平台记录分散于列表 | 同平台分组，逐把显示名称、账号、环境及 API 主机 | 集中查找，同时明确区分复制目标 |
| 第一次添加就面对完整表单 | 选择平台后主要粘贴密钥，其他字段按需展开 | 降低首次录入成本；高级需求仍可完整编辑 |
| 同平台新增沿用相同默认名称 | 自动生成不同编号名，并展开账号与环境提示 | 避免两行完全相同而难以判断 |
| 首页侧栏显示全部工具与分类 | 首页默认折叠工具和分类，管理页仍可展开浏览 | 降低首页信息量，保留已有整理能力 |

## 页面与交互

- 原生 SwiftUI 导航、系统字体、SF Symbols、系统控件、浅色卡片与细边框。窗口变窄时卡片自动换列；不为搜索、复制增加等待动画。
- 「全部 / 模型 / Skill 与服务 / 常用」筛选。先筛选每条记录，再按平台归组，不把不匹配的同平台密钥带入结果。
- 首页搜索名称、平台与别名、账号、环境、标签、关联工具名称，支持跨字段多词组合。密钥正文、网址、备注与额度值不参与首页搜索。
- 每张平台卡片直接展示最多两把密钥；超过两把时提供「查看全部」弹出列表，全部条目仍各有独立复制按钮。
- 每行的更多菜单提供复制 API 地址、加入常用、查看详情、编辑。官网始终使用预设的官方 API 入口；自定义提供商不猜测官网。
- 未保存的平台以添加按钮显示。空库优先显示常用平台图标，可搜索或打开完整 61 项目录；保存后留在首页。工具模板作为可选整理方式，保留 25 项模板。
- `⌘1` 返回首页，`⌘2` 管理全部密钥，`⌘F` 返回首页并聚焦搜索。首页不暗中选择一条记录，因此选中记录的复制、编辑快捷键不会作用于以前看过的密钥。

## 数据边界

本次只增加呈现与录入方式。保留 61 个服务商预设、76 个本地品牌图标、C2 App 图标及全部 12 个候选。加密载荷仍为版本 3，演示目录仍为修订 7；没有新增数据迁移、自动联网、自动额度请求或使用历史采集。

平台归组不合并或删除密钥实体。复制时按记录 ID 查找当前值，沿用剪贴板 30 秒清理及锁定时清理机制；复制反馈只保存 ID 与操作类型，并在两秒后消失。锁定关闭所有草稿窗口、清除首页内容与反馈。Touch ID 与主密码流程保持可用。

验证范围与结果见 [0.8 验证记录](../macos/verification.md)。
