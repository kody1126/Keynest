# 开源 Mac App README 对照与 Keynest 重写

核验日期：2026-10-03。直接阅读六个项目的官方 README 源文件，比较信息顺序与呈现方式；没有复制它们的文案、产品图片或图标。链接指向当时阅读的默认分支文件，后续内容可能变化。

## 原 README 的问题

- 没有嵌入产品截图，读者必须读很多文字才能想象界面。
- 同一层级混放入门操作、字段规则、升级格式、测试记录、旧 Web 实验和图标历史。
- 内部协作约定与本机开发过程进入面向用户的首页。
- 英文版完整翻译了这些负担，没有重新设计信息顺序。

## 本次落地

1. **先看到产品**：C2 图标、简短定位、四个有明确用途的徽章、直接下载和语言切换。
2. **用真实截图说明**：首页大图展示按平台复制；工具选择器放在可展开区域。两图均来自已安装 0.8.1 Demo，只包含虚构样例，没有拼造界面或展示真实密钥。
3. **六项日常收益**：直接取用、多账号区分、平台预设、工具组织、Touch ID、加密备份。
4. **安装和限制就近解释**：Apple Silicon/macOS 要求、三步开始、预览版与未公证状态；Demo 凭据折叠展示。
5. **安全说明保留关键事实**：加密方式、本地存储、自动锁定、剪贴板、额度查询范围及未独立审计边界；实现与检查详情链接出去。
6. **开发与社区收尾**：最短可执行构建步骤、贡献/安全报告、代码与素材许可。
7. **中英一致**：同样的布局、截图、功能和限制。原英文详细内容转为 `docs/guide.en.md`，中文完整说明继续使用 `macos/README.md`，统一从 `docs/README.md` 导航。

不增加尚不存在的 Homebrew 安装命令、App Store 徽章、英文界面、自动更新、全平台实时余额或未经核实的安全认证。此次只改文档与展示图片，不修改 App 行为或重新发布二进制。
