`npm test` 最终结果：33 项全部通过，0 失败（约 2.1 秒）。使用 Node 内置 test runner。上游查询全部 mock，不发送真实凭据，也不发起推理调用。测试项包括：

- 整库密文不包含测试 Key、主密码、名称、标签或备注；文件/目录权限。

## 明确限制

定向回归和代码审查不能代替独立安全审计。`Vault` 的异步变更只能经 server 串行队列调用。真实 provider 的权限、地区网络和当时响应格式仍需用户自行放入测试 Key 后联调。主密码更换、系统钥匙串、原生安装包与后台常驻均未实现。
